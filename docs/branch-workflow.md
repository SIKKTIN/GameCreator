# 分支与原型数据管理

## 分支职责

| 分支 | 用途 |
| --- | --- |
| `master` | 主开发集成分支，汇总已完成的功能，也是新功能开发的起点。 |
| `release` | 稳定发布分支，也是 GitHub 默认分支，从确认稳定的 `master` 更新。 |
| `codex/功能名` | 仅在本地保留的功能分支，从最新 `origin/master` 创建，不上传远端。 |

普通功能按“功能分支 → master → release”的顺序合并。多个任务并行时，各自使用独立功能分支；需要同时运行多个检出目录时使用 Git worktree。`main` 已退役，不再保留或用于开发；后续开发以远端 `master` 为准。新克隆默认检出稳定的 `release`，开始开发时仍须从最新 `origin/master` 创建功能分支。

远端分支只保留 `master`、`release`。其余功能分支只在本地开发和提交。清理远端功能分支前重新核对提交及合并关系，保留本地分支；删除远端分支不会删除已经合入主线的提交。删除退役的 `main` 前，应确认其提交已进入主线，并先将 GitHub 默认分支改为 `release`。

每个新功能开始前，先执行 `git fetch origin` 获取远程最新状态，再从 `origin/master` 创建独立功能分支。保留其他任务未提交的改动，必要时在独立 worktree 中开发或合并。不要强制推送覆盖其他分支的提交。

功能完成后提交功能分支，获取最新远端 `master`，处理合并冲突，并对合并后的版本执行构建、相关单元测试和客户端回归，通过后推送 `master`。如果推送前远端又有新提交，重新集成并验证，不使用强制推送。

推送时显式指定目标，例如 `git push origin master`，稳定发布时使用 `git push origin release`。不要推送本地功能分支，也不要用 `git push --all` 上传全部本地分支。

确认 `master` 上的功能稳定后，再将它合并到 `release` 并推送；首次发布时可从已确认稳定的 `master` 创建 `release`。稳定发布同步独立于日常功能合并。本地运行产生的文件不应随功能提交。

## 本地推送检查

新克隆仓库后执行 `npm run git:install-hooks`。安装器将 `.githooks/pre-push` 复制到 Git 公共目录，供该仓库的所有 worktree 共用，包括仍停留在旧功能分支的 worktree。已有不同 hook 或自定义 `core.hooksPath` 时会停止安装，保留原配置，需先整合现有检查。

检查只允许上传目标分支 `master`、`release`，拒绝 `main` 和其他分支的创建或更新；允许删除退役的 `main` 及其他远端功能分支，但阻止删除 `master`、`release`。标签不属于这项分支限制。此检查是本机 Git 保护，新克隆需要安装，GitHub 网页及其他电脑不会自动继承它。可运行 `npm run test:git-policy` 验证检查规则。

## 代码与项目数据

- `examples/prototypes/` 中的 JSON 是可重复使用的设计示例，随 Git 分支和客户端构建分发。
- `.gamecreator/` 是当前检出目录的运行数据，包含本地项目、素材、测试工作区和团队数据库，被 Git 忽略。
- 合并或切换分支不会将一份检出目录的运行数据复制到另一份目录。
- 新机器或新工作树可通过客户端的“从原型示例创建项目”入口建立自己的本地副本。每次创建使用独立项目身份，之后的编辑不会改变仓库中的示例。
- 团队共享以各模块实际接入的服务端能力为准；创建原型本地副本不等于上传完整项目到团队服务器。

示例内容需要更新时，单独更新相关 JSON 并运行 `node scripts/validate-prototype-examples.mjs`，不要把整个本地存档目录加入 Git。

已编辑的本地项目通过“导出项目到文件夹 / 从文件夹导入项目”迁移完整内容和美术交付文件，详见 [项目文件夹迁移](project-package.md)。`ProjectCache/` 是 Git 忽略的本机导出目录；运行数据的迁移与源代码分支合并分别进行。

本地项目列表右键的“打开数据文件夹”会打开实际运行数据的 `storage/` 目录，并定位所选项目已存在的存档文件；尚无模块存档时只打开目录，不创建占位文件。该位置跟随 `GAMECREATOR_DATA_DIR`，默认位于当前检出目录的 `.gamecreator/storage/`，与引擎连接路径无关。当前存档按项目身份分文件存储在共享目录中，素材原文件另存于 `.gamecreator/art-files/`；完整迁移仍使用项目文件夹导出。
