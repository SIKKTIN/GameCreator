# 测试面板

## 打开与关闭

管理员登录后，可点击顶部“测试面板”，或在普通页面区域按 Space 打开浮层。
Esc、关闭按钮和浮层外侧点击可以关闭；焦点在浮层本身时再次按 Space 也可关闭。
关闭后恢复原焦点，Tab 焦点限制在浮层内。

输入框、文本编辑区、中文输入法选词、按钮和下拉框保留正常键盘操作。
长按 Space 不反复切换，带 Ctrl/Alt/Shift/Meta 的组合键不触发。
普通用户不显示入口，也不注册测试面板快捷键。

## 枚举测试

桌面客户端提供八个预设：首次导入、无变化、新增成员、删除成员、修改成员、混合变化、删除被引用成员、异常来源。

点击“加载…”后，客户端会创建独立 Lua 测试工程，通过实际扫描器读取内容，并建立该场景的测试基线及候选版本。
随后进入现有枚举管理页面，可进行同意/不同意、同步、数据引用修正和回退等操作。
测试面板显示初始预期、当前变化数量，并提供进入枚举管理、查看枚举定义及重置入口。
异常来源使用不存在的测试目录，验证扫描失败后已发布定义仍然保留。

测试期间顶部持续显示“测试工作区”横幅。来源设置固定，正式引擎配置不被改写。
测试工作区不生成正式 AI 导出文档；诊断信息可以在面板中复制。

## 隔离与恢复

文件保存在 GameCreator 的 `.gamecreator/test-workspaces/<运行编号>/`：

- `project/Script/Const/`：本次运行的 Lua 来源。
- `storage/`：本次运行的枚举、数据配置和项目信息存档。

测试工作区中的表目录、故事、项目介绍等也使用独立键保存。
当前测试会话的位置保存在 `gamecreator.test-session.v1`，重启并以管理员登录后恢复该测试工作区。
“返回原工作区”恢复原来的工程设置与正式存档。

“重置当前场景”创建一个新的同类运行并切换过去，清除当前视图中的测试操作；旧测试目录保留，正式数据及其他测试存档不删除。
这些文件遵循 `.gamecreator/` 的 Git 忽略规则。

## 通用调试

可查看当前页面、账号、运行环境、工作区、版本、成员数量、审核统计、存档修订、位置、最近磁盘保存时间及错误。

- **运行只读检查**：读取存档，核对内存修订号、稳定版本与数据校验，并与测试场景预期对照。
- **复制诊断信息**：复制 JSON 报告，包含状态和最近操作日志；失败时可以展开诊断信息手动复制。
- **清空面板日志**：仅清空本次启动的内存日志，不删除存档或版本历史。

操作日志记录扫描、审核、同步、回退、配置编辑及存档写入的成功或失败，最多保留 200 条。
浏览器开发模式可使用通用调试；枚举场景需要桌面客户端的文件创建能力。

## 验证

```powershell
npm run build
node --test tests/enum-bindings.test.mjs tests/enum-versions.test.mjs tests/desktop-storage.test.cjs tests/test-workspaces.test.mjs
```

使用 Playwright 运行隔离的桌面验收（可设置 `GAMECREATOR_PLAYWRIGHT_PATH` 指向已安装模块）：

```powershell
node tests/desktop-test-panel.cjs
node tests/desktop-enum-review.cjs
node tests/desktop-restart.cjs
```
