# 枚举更新检测与外部导入

## 两个内部标签页

“枚举管理”默认进入“枚举更新检测”，另一个标签页为“外部导入”。

- **外部导入**：读取引擎设置中的 Lua 枚举目录，展示来源文件、只读预览与未导入的动态定义。导入只产生候选内容。
- **枚举更新检测**：对比候选内容与已发布定义，审核后统一同步。点击“检测更新”可重新读取同一目录。

## 审核操作

变更用颜色及文字共同标识：新增绿色、删除红色、修改黄色。删除的成员仍显示在审核列表。
支持按名称、成员和说明搜索，以及全部、仅变化、新增、删除、修改筛选。
内容始终只读；实际值、注释和排序差异可在“查看差异与影响”中展开查看。

每项变更初始为“待决定”，只提供“同意 / 不同意”。一组有多项变化时可对本组全部变更统一决定。
新增/删除整组按整组审核，已有组的成员和说明等变化可分别决定。
审核人取当前登录账号，审核摘要自动生成，无需编辑名称、值或说明。

决定自动保存，但此时枚举定义和数据下拉框不会变化。
点击“同步已同意的变更”后，仅已同意且通过校验的内容进入稳定版本。
不同意或待决定的内容保留现有定义，部分同步后仍可继续审核剩余差异。

## 重复检测与重新审核

相同变更保留已有决定，包括刷新、重启和再次导入。
来源内容或对应的稳定定义变化时，受影响变更重新变为待决定；无关变更的决定保留。
旧版自动预选的候选项升级后改为待决定，避免将旧版默认勾选当作用户明确同意；历史发布记录保持不变。

## 引用保护

审核页不提供成员替换、改值或数据迁移编辑。
删除仍被记录使用的成员、或仍被字段绑定的整组枚举时，阻止同步并指出引用。
应先到“数据配置”修正引用，再回来同意同步删除；也可不同意此项，先同步其他变更。
重命名仍按删除旧成员和新增成员呈现，可先同步新增，再在数据配置调整引用，最后同步删除。

发布前继续检查重复值、重复成员、混合类型、审核基准等。
既有数据问题仍由数据配置页的全工程导出检查提示，候选定义不参与解析或导出。
Lua 文件生成和写回 Withdraw 源文件尚未接入。

## 历史与持久化

底部折叠的版本历史保留同步、回退、检测和决定记录。
回退前检查当前字段与记录，避免恢复出新的无效引用；旧版本已有迁移历史仍兼容读取和回退。
如果回退使候选的审核基准失效，需重新检测。

枚举、审核决定、稳定版本和数据草稿在同一次存档提交中保存。
Electron 使用本地磁盘存档，浏览器开发模式使用 localStorage；详见 [本地数据持久化](persistence.md)。

## 验证

```powershell
npm run build
node --test tests/enum-bindings.test.mjs tests/enum-versions.test.mjs tests/desktop-storage.test.cjs
```

已安装 Playwright 或设置 `GAMECREATOR_PLAYWRIGHT_PATH` 后，可运行隔离桌面验收：

```powershell
node tests/desktop-enum-review.cjs
node tests/desktop-restart.cjs
```

验收覆盖真实 Lua 导入、彩色差异、只读控件、决定重启恢复、部分同步、拒绝决定保留和引用删除保护，不修改真实工程和用户存档。
