# 玩法核心

玩法核心在一张主图上表达玩家如何进入游戏、选择玩法、经历活动并形成循环。它不代替玩法设计文档：节点负责串起整体体验，详细规则仍在关联的玩法文档中。

节点分为入口、活动、模块、判断和出口。节点可记录说明，并关联多个已有玩法。连线可写名称与条件，例如“胜利”“时间与精力足够”。出口是可选的，农场生活或持续探索可以只有循环。

模块可展开为独立内部图。内部图只属于一个模块，可以继续包含下级模块；图内允许回环和自环，图与图之间保持树状层级。模块的内部图不会因为关联的玩法文档被改名而丢失；关联失效时显示提示，保留原引用以供修复。

## 操作

点击画布上方按钮添加入口、活动、循环模块、条件分支或结束节点。选择“连线”，依次点击起点和终点；也可以连接自身。点击节点或连线，在属性面板编辑名称、说明、条件和已有玩法引用。左键拖动节点调整布局；鼠标停在画布内滚动滚轮，以鼠标位置为中心缩放。按住右键拖动可平移画布，在节点上按右键也不会改动节点位置。缩放与平移只改变视图，不修改存档。双击循环模块进入内部图；模块目录和顶部路径可返回上层。放大、缩小和适配按钮位于画布底部；“适配画布”或“还原缩放”可将移远的画布恢复。画布外的模块目录和属性面板保持正常滚动。

在空白画布按住左键拖出选框，可选中与框相交的多个节点（支持任意方向）。拖动任一选中节点会整组移动，所有连线同步跟随；抵达布局边界时整组停止，节点间距保持不变。Shift 点击可加选或取消单个节点，Shift 框选保留已有选择；“全选节点”或聚焦画布后 Ctrl/Cmd+A 选择当前流程全部节点。多选属性面板列出已选节点，点击其中一项可恢复单节点编辑。

点击空白或按 Esc 清除选择；拖动中按 Esc、窗口失焦或指针取消会撤销本次移动。切换流程不会保留上一层的选择。框选和选择状态不写入项目；拖动结束后一次保存整组位置，失败时保留完整草稿并支持重试。连线模式保持原操作，不触发框选。

删除循环模块需要确认，内部所有图与相关连线会一同删除，关联的玩法设计仍保留。

## 保存与迁移

每个项目独立保存 `gameplay-core` 存档，包括图层级、节点坐标、连线条件和玩法引用。已有项目没有这份存档时，显示空的主图，不推测或自动生成用户的核心玩法。

“导出项目到文件夹”将完整核心保存到 `data/gameplay-core.json`，与其他模块一同加入 `manifest.json` 的大小及 SHA-256 校验。导入保留图和节点标识、坐标与所有关联；导入的是新的独立项目。旧版项目文件夹没有该文件时仍可导入，自动使用空主图。损坏的图结构会阻止导入，未完善的文档关联可以作为草稿保留。

磁盘写入失败时保留当前草稿，显示重试入口并阻止切换项目或退出登录。若其他窗口已更新存档，可先“导出当前草稿”备份，再选择“重新读取存档”载入最新版本；有未保存修改时会要求确认。损坏的存档不会自动被空图覆盖，仍可切换到其他项目。

AI 文档包括玩法核心的层级、节点、连线条件和关联玩法，便于把整体流程与具体设计一同交给程序或 AI。

## 原型示例

- 植物大战僵尸：入口分支为挑战、无尽和花园。挑战展开为选植物、守卫关卡、奖励、下一关与最终首领；无尽和花园表达持续循环。后两者及最终首领是扩展示意，尚未宣称已经实现。
- 星露谷物语：以新的一天、安排活动、休息与日结算构成主循环，展开农场、钓鱼、矿洞和社交。没有强制终点；钓鱼与矿洞为待细化的扩展模块。
- 空洞骑士：探索发现战斗、能力试炼与路径门槛，成长解锁路径后回到探索；内部图关联现有移动、战斗、长椅、冲刺试炼和近路文档。

- 极乐迪斯科：自由调查展开为探索取证、对话与技能检定、思想内化及日程，案情汇报形成三种阶段结果。具体剧情和数值为原创原型约定。

官方示例的图只随“从原型示例创建项目”写入新项目。升级不会自动覆盖本机已经修改过的原型存档。

## 验证

`node --test tests/gameplay-core-portability.test.mjs tests/project-package.test.mjs tests/project-package-files.test.cjs tests/prototype-import.test.mjs` 覆盖原型创建、旧格式兼容、图的完整往返、失效引用草稿、文件哈希与损坏结构拒绝。

`node scripts/validate-prototype-examples.mjs` 校验四个官方示例的图结构和玩法引用。

构建后运行 `node tests/desktop-gameplay-core.cjs` 可验证图形编辑、嵌套导航、真实持久化、冲突恢复、项目隔离与窄窗口布局。

构建后运行 `node tests/desktop-core-navigation.cjs` 可验证滚轮锚点缩放、右键平移、组合按键、取消与失焦恢复，以及视图操作不改写项目存档。

`node --test tests/core-selection.test.mjs` 检查框选命中和整组位移边界。构建后运行 `node tests/desktop-core-selection.cjs` 检查缩放/平移/滚动后的框选、多选拖动、取消、单次保存与失败重试、层级切换和重启；`node tests/desktop-team-core.cjs` 覆盖两名成员与只读成员的整组个人布局隔离。

## 团队项目

服务接口版本 7 起可以协作编辑玩法核心。节点、连线和说明先保存本机草稿，再提交到团队；各流程分别检测版本冲突。节点拖动只保留个人布局，缩放和平移也不产生团队修改，只读成员可以调整布局。框选和整组拖动同样只保存到当前账号、当前项目的本机个人布局，一次提交全部节点位置；不会产生团队内容提交，也不会改变其他成员的排布。删除循环模块同时检查所有下级流程版本。

本地项目发布会包含玩法核心；旧发布项目可在团队尚未编辑玩法核心时补充一次。发布时保留玩法设计的来源名称和 ID，团队中暂不开放玩法设计跳转与修改。具体权限、冲突处理和数据位置见 [多人协作](collaboration.md#玩法核心协作接口版本-7)。
