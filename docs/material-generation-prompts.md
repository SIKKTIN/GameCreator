# 素材资产与生成提示词

模块名称统一为“素材资产”，界面使用“素材需求”“素材分类”“素材验收标准”。玩法、地图、任务、项目排期及导出界面的关联入口同步改名。技术标识 `art-assets`、文件标识和原有项目 ID 保持不变；制作方向中的“美术”仍表示人员分工。

需求详情的“需求说明”之后增加独立的“素材生成提示词”卡片：

- **生成提示词**与可选的**避免内容**可直接编辑，沿用素材需求自动保存。
- **从需求整理**使用名称、描述、规格和验收标准在本地组织草稿，依据音频、动画或视觉素材提供描述提示。它不调用外部模型，不会推断未填写的分辨率、风格或时长。
- 草稿始终先预览，可继续编辑，按“使用草稿”替换当前两项内容；取消或关闭不修改原需求。已有避免内容会带入新草稿。
- **复制提示词**复制主提示词及避免内容，可粘贴到 AI 工具中。复制失败明确提示手动复制。
- 展开编辑提供更大的文本区域。归档需求只读，已有提示词仍可复制。

`ArtRequirement.generationPrompt` 是可选字段，结构为 `{ prompt: string, negative: string }`。老存档不要求补字段，打开时显示空白；只有编辑或采用草稿才写入。修改其他需求信息不会自动重写提示词。

提示词包含在项目 AI 文档及文件夹导出中，恢复项目后保持原文；桌面文件夹边界也校验字段类型。分类、交付版本、文件、审核状态与排期关联均保持原有语义。

验证包括：旧数据只读与形状校验、本地草稿组织、归档/并发保护、真实文件夹往返、手动编辑、预览取消/采用、复制成功/失败、保存失败重试、项目隔离、重启、窄屏，以及原有文件交付流程。
