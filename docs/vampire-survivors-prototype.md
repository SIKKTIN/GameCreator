# 吸血鬼幸存者 · 暮色荒原原型

第五套内置示例用于表达自动攻击生存游戏的局内构筑与跨局成长。地图、角色、数值、30分钟达标裁决、动画尺寸和美术要求均为本原型的设计约定。参考原作的核心机制，不声称覆盖原作全部内容或当前平衡。

## 打开与范围

项目列表 → 从原型示例创建项目 → 吸血鬼幸存者。每次创建独立本地项目，已有项目不被覆盖。

包含 8 张玩法核心图、9 份玩法设计、9 个程序系统 / 24 项功能、16 张配置表 / 268 条记录、4 篇说明文档、26 项美术需求 / 42 项资产台账。

原型范围为一张30分钟无限平铺荒原、3名角色、6种基础武器、6种被动、3条进化、6类敌人、12个怪潮阶段与6次精英事件。无尽、联机、塔罗牌和更多地图留待后续。

主入口连接选角、生存、结算、永久成长和图鉴。生存内展开固定战斗步、怪潮导演、经验选择和精英宝箱；结算返回主入口，永久内容影响下一局。流程图、条件、状态、空间对象、时间事件和功能/资产使用关系均使用稳定ID。

## 核心契约

- 世界时钟只在 Playing 运行，升级/开箱/暂停/结算冻结模拟。经验选择优先于宝箱，宝箱FIFO处理，同一时刻只有一个奖励面板。
- 帧开始已经死亡则阵亡；否则下一时刻到1800秒即先锁定生存达标，不执行该步后续战斗。未达标时处理伤害，再死亡判定，最后处理奖励。5秒终场演出可跳过，不要求击杀死神，不改变收益。
- 武器与被动各6槽，基础武器8级，被动5级；进化原槽替换、结果1级、所需被动保留。等级表为当前级完整数值，永久强化表才是逐档增量。
- 候选只含已解锁、未满级、未放逐的合法项；新装备还需空槽，已进化旧形态排除。最多3个不同候选，空池提供回血25或金币10。重抽/跳过/放逐每局分别2/1/1次。
- 经验等级80封顶。成长倍率开局固定，本次计入经验是 `floor(累计原始经验 × 成长倍率) − 已计入经验`。地面经验合并不改变累计原始值，因此合并和拾取顺序不会改变总收益。
- 生成环以玩家实时位置为中心，半径20–26米，位于32×18米逻辑视野以外。空间布局只是周边关系示意，不是固定网格或地图边界。
- 普通怪潮使用 `[start,end)`，每150秒换段，每2秒生成请求；超量丢弃，不补刷。精英满容量时等待空位，原事件的生成时间与宝箱资格不改变。70米外回收不计击杀，不掉经验。
- 宝箱资格取精英原计划事件，300秒的箱子晚开也不能进化。合格箱按配方priority升序进化至多一把；不合格则给已持有未满级、未放逐项目升级，没有可升级项则额外20金币。每箱还有固定30金币。
- 阵亡收入为拾取金币加每整分钟2金币；生存达标另加100；主动放弃只保留拾取金币，不推进成就统计。每个runId只提交一次，失败保留冻结结果重试。
- 永久购买同时扣金币和增加下一档，不允许乱序。解锁在结算生效，下局重建装备、等级、经验与选择次数；不继承上一局构筑。
