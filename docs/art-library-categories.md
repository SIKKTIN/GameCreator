# 美术资产分类导航

美术资产采用“分类卡片 → 分类内目录 → 详情”的结构，与玩法设计的分类入口保持一致。分类内通过“制作需求 / 资产文件”切换；原有规格、来源、交付版本、审核与采用功能保持原流程。

- 首页支持跨分类搜索名称、说明、负责人和交付文件名，以及有效/归档范围筛选。
- 分类卡片显示需求、资产数量和待制作、待验收、已通过的需求数量。这里的待验收对应需求状态“待审核”，不代替交付版本审核。
- 可新建、重命名、编辑说明、排序和删除分类。详情页的“所属分类”可移动需求或资产，包括整理已归档内容；归档正文仍不可编辑。
- 删除分类只移入“未分类”，不删除条目、文件或关联。需求与资产独立归类，共用资产仍通过已有关联服务多个需求。
- 旧的“分类”字段在需求编辑器显示为“制作类型”，保留其既有技术含义；目录归属由“所属分类”维护。

## 旧存档与持久化

`ArtStore.library` 是可选的目录元数据，包含分类列表和需求/资产 ID 到分类 ID 的映射。旧 `schema: 1` 存档仍然有效。

首次显示时只读推导初始目录：按旧制作类型归类；明确标识为声音的需求归音频，角色类型中明确标识为敌人/首领的归相应目录。资产仅在其关联需求都归于同一分类时继承该分类；无法确定或跨分类的共用资产进入未分类。

打开页面不会写入存档。首次美术编辑会连同目录保存，此后以人工目录为准，不随名称修改或需求关联变化自动移动资产。新条目继承当前分类，从全局入口创建则进入未分类。

分类元数据随美术存档持久保存，也随项目文件夹包转移。所有需求、资产、版本、文件和来源 ID 保持不变；分类操作不更新业务状态或排期。保存沿用现有版本冲突检测、失败草稿与重试保护。
