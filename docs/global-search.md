# 全局搜索

入口：左侧「全局搜索」、顶部搜索框按 Enter、Ctrl+K（macOS 为 Cmd+K）。原生对话框打开时不抢占快捷键。

## 搜索范围

仅搜索当前项目。支持项目概览、玩法核心、玩法设计、功能系统、素材资产（含生成提示词及文件名称）、原型设计、地图设计、故事文档/编排、数据配置、已发布枚举、项目排期、任务与流程及数值分析方案。

索引从已加载的数据建立于内存，切换项目时销毁。它不修改业务存档、不读取凭据、不打开素材文件或执行其内容、不把内容发给外部搜索或 AI 服务。没有持久化搜索历史。

团队工作区只索引授权请求返回的共享版本；未提交草稿不计入搜索。尚未共享的模块和其他本地项目不会混入结果。收到拒绝访问或会话失效状态后清空结果和预览。暂时断网时保留最后一次获准读取的快照并显示同步提示。

## 匹配与导航

- 名称/ID 精确匹配优先，其次名称部分匹配、路径及正文。空格分隔的多个词需要全部命中；不区分英文大小写，不执行正则表达式。
- 每个可定位条目只出现一次，多个字段命中合并。父文档和它的规则、状态、对象是不同条目。
- 默认排除归档内容，可开启「包含已归档内容」。系统归档会影响其功能的归档状态。
- 模块筛选、结果正文预览、已有直接关联；关联只使用记录中的引用 ID，不由关键词推断。不同表/子集合出现相同 ID 时不猜测引用对象。
- 支持跳到文档及子项、功能、素材需求/资产、节点/连线、场景元素、地图对象/连接、故事片段、配置记录、枚举成员、制作任务与里程碑。
- 返回搜索保留词语、筛选、预览及结果列表滚动。离开目标模块后清除导航请求，避免之后手动打开模块被旧结果干扰。
- 删除/不可访问的条目重新验证；关闭的模块提示先启用。共享结果与当前未提交草稿不一致且目标已不存在时，返回搜索说明情况，不跳到其他条目。

## 实现与验证

`src/global-search.ts`：数据适配、内存索引、排序与直接引用。
`src/GlobalSearch.tsx`：项目搜索上下文、团队快照注册、入口、预览和目标定位请求。
每批显示 40 条，输入防抖 160ms。模型回归包含 12,000 条记录及长正文。

验证命令：

```powershell
npm run build
node --test tests/global-search.test.mjs
node tests/desktop-global-search.cjs
node tests/desktop-team-global-search.cjs
```

桌面测试使用隔离临时存储与团队数据库，不修改用户项目。Playwright 可通过 `GAMECREATOR_PLAYWRIGHT_PATH` 指定。
