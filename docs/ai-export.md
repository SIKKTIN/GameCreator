# AI 文档导出

客户端顶部的“生成 AI 文档”会把当前工作区整理成一个 Markdown 文件，适合交给 AI 做检索、总结、审阅和协作。内容包括：

- 项目概览和版本信息
- 引擎目录与同步设置
- 稳定枚举版本、来源、行号、注释和动态 ID 提示
- 故事文档、标签、大纲和关联设定
- 数据配置表格

在 Electron 本地客户端中，文件写入项目根目录的 `generate/`。浏览器开发模式会使用浏览器下载功能，因为浏览器不能直接写入项目目录。

不同项目使用各自的文件名，避免同日导出互相覆盖。文件名格式：`gamecreator-<工程标识摘要>-context-YYYY-MM-DD.md`。

玩法设计会作为独立章节导出，包括体验目标、核心循环、规则、原型制作项、暂缓内容、试玩验证记录和关联文档或配置表名称。也包括玩法依赖与反向引用、条件组合和两条动作分支、状态起点和转移条件/动作/优先级，以及空间尺寸、对象坐标/占地/方向/范围、轨道事件的开始/持续/重复/数量/位置与结构不完整时的检查提示。时间计划数量不代表存活数量。归档方案明确标记为已归档，失效关联会保留提示。
