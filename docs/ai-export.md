# AI 文档导出

客户端顶部的“生成 AI 文档”会打开导出设置窗口，一次生成一份完整总文档和每个内容模块各自的 Markdown，适合交给 AI 做检索、总结、审阅和协作。总文档继续包含所有导出章节。内容包括：

- 项目概览和版本信息
- 项目排期：制作任务、里程碑、计划与实际日期、负责人、依赖、内容来源、验收记录及待处理提醒
- 引擎目录与同步设置
- 稳定枚举版本、来源、行号、注释和动态 ID 提示
- 故事文档、标签、大纲和关联设定
- 数据配置表格
- 任务阶段和分支；启用故事编排时的完整正文、角色状态、选项条件、后果、检定与叙事结果。

## 保存位置与文件名

在 Electron 客户端中，可以选择或填写保存位置，自定义输出文件夹、总文档和每个模块文档的名称。默认保存位置仍为客户端根目录的 `generate/`，默认文件夹为“项目名称-AI文档-本地日期时间”。文件名支持中文和空格，省略 `.md` 时自动补齐；非法名称、Windows 保留名称和同目录重复文件名会阻止生成。

```text
选择的保存位置/
└─ 项目名称-AI文档-2026-09-21-103000/
   ├─ 项目完整文档.md
   └─ 模块/
      ├─ 项目概览.md
      ├─ 项目排期.md
      ├─ 玩法核心.md
      ├─ 玩法设计.md
      ├─ 原型设计.md
      ├─ 功能系统.md
      ├─ 素材资产.md
      ├─ 故事文档.md
      ├─ 数据配置.md
      ├─ 枚举定义.md
      ├─ 枚举管理.md
      ├─ 引擎设置.md
      ├─ 任务与流程.md
      └─ 数值分析.md
```

地图设计和故事编排启用时增加对应模块文档；关闭时同时从总文档与文件清单中省略。常规模块即使没有条目也会输出，并注明暂无内容。全局搜索、服务器管理等工具页不作为项目内容导出。

同名输出目录自动追加 ` (1)`、` (2)` 等序号，保留原目录及文件。生成后展示实际保存位置、文件数量，并提供“打开文件夹”。成功后按项目记住保存位置及命名设置；这些本机偏好不作为项目内容打包。取消不会生成文件。写入先在临时目录完成，再占用一个全新的输出目录，失败时清理本次生成的文件，不覆盖已有导出。

浏览器模式下载 ZIP；解压后的结构与桌面端一致，下载位置由浏览器控制。Markdown 使用 UTF-8，ZIP 支持中文目录与文件名。

## 内容一致性

总文档和模块文档由同一份模块章节组装，使用同一项目版本和生成时间。总文档包含模块文件的相对链接，模块文档包含返回总文档的链接；修改文件名后链接同步更新。每份模块文档可独立阅读，保留原有的关联名称、ID、归档状态及设计提示。

读取失败、尚未保存或枚举/配置正在更新时停止导出；测试工作区继续禁止正式导出。导出设置窗口会显示问题，写入错误后保留设置以便重试。导出不调用外部 AI 服务。

玩法设计会作为独立章节导出，包含分类目录、每篇文档的分类路径和标签，以及体验目标、核心循环、规则、原型制作项、暂缓内容、试玩验证记录和关联文档或配置表名称。也包括玩法依赖与反向引用、条件组合和两条动作分支、状态起点和转移条件/动作/优先级，以及空间尺寸、对象坐标/占地/方向/范围、轨道事件的开始/持续/重复/数量/位置与结构不完整时的检查提示。时间计划数量不代表存活数量。归档方案明确标记为已归档，失效关联会保留提示。


## 功能系统与实现引用

导出按系统组织功能规格，包含输入、条件、处理流程、输出、异常和验收要点。每个完整功能仅定义一次；玩法章节引用功能名称与ID，系统章节反查玩法及具体规则、状态或时间事件。配置值从当前项目数据解析，失效、归档与依赖检查结果一并保留。功能系统未保存或读取失败时停止导出。

## 美术需求与交付

导出集中列出每项美术需求和资产一次，包含制作规格、来源、审核反馈、占位标识、版本历史和当前采用版本。玩法与功能章节列出关联美术需求，文件以名称、存储标识和元数据描述，二进制内容不嵌入 Markdown。美术存档读取失败或未保存时停止导出。

## 可选故事编排

模块启用时导出每个故事的场景、全文、角色、状态、开放条件、选项后果、检定成败后继、时间与中断规则，保留归档标记和设计检查提示。关闭模块时省略此章节，项目文件夹备份仍保留全部故事。试玩过程不写入 AI 文档；未保存或存档读取失败时停止导出。

项目人物库集中导出背景、动机、性格、说话风格、肖像引用与人物关系；各故事列出出场引用和自定义叙事发言者。状态使用自定义标签，检定注明数值比较或骰子数量、面数与极值规则。

## 可选地图设计

模块启用时导出区域、地图、图层、实时来源与本地对象布局、内容关联、出入口和通行条件。关闭时省略 AI 文档章节，完整项目文件夹仍保留地图数据。未保存或存档损坏时停止导出，避免文档与已保存布局不一致。

## 实现与验证

- `src/ai-export.ts`：按模块生成章节、组装总文档及文件清单；保留 `buildAiMarkdown` 的原调用方式。
- `src/AiExportDialog.tsx`：导出设置、项目偏好、校验和结果反馈。
- `shared/ai-document-files.mjs`：桌面端与界面共用文件名及路径校验。
- `desktop/ai-documents.cjs`：目录命名冲突处理、批量写入、失败清理和输出目录定位。
- `src/ai-document-zip.ts`：浏览器 ZIP 打包。

```powershell
npm run build
node --test tests/ai-document-export.test.mjs tests/ai-document-files.test.cjs
node tests/desktop-ai-document-export.cjs
```

桌面回归使用隔离临时存档和目录，覆盖路径选择及取消、中文命名、重复名称、写入失败重试、文件内容、项目设置隔离、可选模块、同名输出保留、打开目录以及浏览器真实下载。ZIP 兼容性通过 Python 3 标准库 `zipfile` 校验；应用运行不依赖 Python。Playwright 路径可以通过 `GAMECREATOR_PLAYWRIGHT_PATH` 指定。
