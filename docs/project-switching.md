# 项目切换与独立存档

## 切换已有项目

点击左上角当前项目名称，展开项目列表。当前项目带有勾选标记。选择另一项后，项目概览、故事、数据配置、枚举和引擎设置会一起加载该项目的存档。

项目名称可以在“项目概览”修改，列表中的名称随之更新。每个项目拥有固定的内部标识；改名、连接工程或更换目录都不会建立新存档。多个项目可以引用相同的游戏工程目录，并各自保有独立的内容与枚举审核进度。

项目列表及当前选择会自动保存。桌面软件重新打开后恢复最后选择的项目，无需重新创建或导入已保存的枚举。普通用户可以切换列表内的项目，新建入口仅向管理员开放。

## 从项目列表删除

本机管理员可在项目列表中右键点击一个本地项目，选择红色“删除项目”，核对项目名称后确认。也可聚焦项目条目，按 Shift+F10 打开操作菜单。右键不会切换当前项目；取消或按 Esc 不会删除。

删除只移除该项目在本机列表中的登记，存档、导入的美术文件、外部游戏工程及已导出的项目文件夹均保留。此操作不用于释放磁盘空间。团队项目不提供删除入口，普通用户仍只能切换项目。

删除当前项目后会选中相邻的本地项目；删除最后一个项目后显示空工作区，重启仍为空，可继续新建、导入或连接团队项目。同名新项目使用新的独立标识，不会恢复被移除的旧存档。项目列表写入失败时保留原列表，可重试。

## 新建项目

1. 点击左上角项目名称，再点击“新建项目”。
2. 填写项目名称。
3. 点击“创建并切换”。

创建时无需准备游戏工程目录或枚举目录，适合从创意和早期原型开始整理项目。新项目立即拥有独立存档，可以先编写项目介绍、故事文档、里程碑和配置数据。

新项目的初始内容：

- 项目名称使用创建时的名称，简介为空。
- 故事文档和里程碑为空。
- 配置表为空，从“数据配置 → 新建配置表”添加当前项目需要的表。
- 没有已发布的枚举，也未连接外部游戏工程。

新项目不会复制其他项目的故事、记录或枚举版本。创建操作不会生成游戏工程或 Lua 源文件。

## 在引擎设置中连接工程

需要读取游戏工程中的枚举时，进入当前项目的“引擎设置”，填写工程目录与工程内的枚举相对目录。数据输出目录和其他引擎选项也在这里配置。

修改这些字段时，内容先保留在设置草稿中；点击“保存设置”后才应用到当前项目。未设置工程目录时不会扫描枚举，也不会因为尚未连接工程而报告连接失败。

保存有效的工程配置后，扫描得到的候选内容仍需在“枚举管理 → 枚举更新检测”审核并同步，才会出现在“枚举定义”中。工程已经连接但枚举来源存在问题时，可修正设置并保存，再到“外部导入”重新检测。

可以更换工程目录，也可以清空工程目录并保存，暂时断开外部连接。这些操作只改变当前项目的引擎配置，项目介绍、故事、配置记录和已保存的枚举版本仍属于原项目，不会被移到另一个存档。切换项目后，引擎设置随所选项目恢复。

## 数据如何隔离

每个项目独立保存以下内容：

| 内容 | 切换后的行为 |
| --- | --- |
| 枚举稳定版本、候选版本、审核决定和历史 | 加载所选项目的审核进度和可用定义 |
| 配置表目录、名称、字段与数据记录 | 加载所选项目的表和数据 |
| 项目介绍、故事文档与里程碑 | 加载所选项目的内容与进度 |
| 引擎配置 | 加载所选项目的工程目录、枚举目录、数据目录和其他选项 |

桌面存档集中保存在 GameCreator 的 `.gamecreator/` 下，按固定项目标识隔离，不需要在游戏工程里放置存档文件。新项目使用 `project-<UUID>` 标识；升级前的项目保留原标识及存档位置。工程目录只用于连接外部来源，不决定项目身份。

位置、备份和旧版迁移说明见 [本地数据持久化](persistence.md)。

## 测试工作区与正式项目

在项目 A 中加载测试场景后，左上角显示测试工作区，并在列表中保留正式项目。测试工作区独立保存测试数据。

- 点击横幅或测试面板中的“返回原工作区”，回到进入测试前的项目 A。
- 在左上角直接选择项目 B，会退出测试模式并切换到项目 B。
- 在测试模式下新建项目，成功后也会退出测试模式并切换到新项目。
- 在测试模式退出软件，重新打开并以管理员登录后，可恢复该测试工作区；返回操作仍指向进入测试前的正式项目。

测试操作不会覆盖正式项目存档，详情见 [Space 测试面板](test-panel.md)。

## 浏览器开发模式

浏览器开发模式也可以仅凭名称新建项目和切换已有项目。此模式使用当前浏览器来源的 localStorage，与桌面磁盘存档相互独立；更换浏览器、地址或端口后可能看不到原列表和内容。需要稳定的本地存档时使用 Electron 桌面客户端。

升级后首次打开已有项目时，会清理未编辑、未使用的五张默认空表（Items、Characters、Skills、Economy、Shop）。有记录、修改过名称或字段、被其他配置/玩法/功能或历史迁移引用的表会保留。此清理每个项目只执行一次，之后主动创建的同名表不受影响。
