# 工程内容同步

在桌面客户端的「引擎设置」中使用「工程连接 / 同步配置 / 待同步变更 / 同步记录」。适用于已连接的 Godot 4 与绿洲启元本地工程。

## 使用

1. 在工程连接选择引擎、配置并保存实际工程根目录。
2. 在同步配置选择文档模块、是否交付已采用素材、是否包含占位版本。填写工程内的相对目录；可使用 Godot `res://` 写法。默认分别为 `docs/gamecreator`、`assets/gamecreator`。
3. 保存配置并预览变更。绿色是新增，黄色是更新，红色是待移除或冲突。
4. 冲突必须选择「保留工程文件，本次跳过」或「备份并使用 GameCreator 版本」。待移除文件另需勾选确认。点击「同步到工程」。
5. 同步记录显示实际交付的文件、采用版本、失败信息及备份位置。文件同步完成不等于已确认引擎导入成功。

同步配置顶部显示「工程连接」已保存的游戏工程根目录，每类内容下方显示拼接后的最终写入位置。修改工程连接但尚未保存时，不能预览或应用同步；保存并切换工程后旧预览失效，后续文件直接写入新连接的工程根目录下。

文档与素材同步需要桌面客户端；浏览器仍可独立导出 AI 文档。同步偏好按本地项目和引擎保存，切换项目互不干扰。新导入的项目副本需要重新选择工程、设置同步偏好，不自动继承另一台电脑的同步权限或工程所有权。

## 输出与版本

- 文档使用现有 AI 文档章节，生成 README 索引和选定模块的 Markdown。固定模块 ID 用于文件名，章节名变化不会改变路径。输出不包含每次变化的生成时间，因此重复检查不产生虚假更新。
- Godot 文档目录写入 `.gdignore`，用于开发查阅，避免作为游戏资源导入；可从系统文件管理器或代码编辑器查看。绿洲启元工程发布时按自身发布规则排除开发文档。
- 素材只选择未归档资产的采用版本。正式版本须审核通过；占位版本由同步配置控制。需求文字、未采用版本不会变成素材文件。
- 常见图片、音频、视频、字体和模型源文件原样复制。支持 PNG/JPEG/WebP/GIF/SVG/BMP/TGA/EXR/HDR/DDS/KTX、WAV/OGG/MP3/FLAC、MP4/WebM/OGV、GLB/GLTF/FBX/OBJ/MTL/Blend、TTF/OTF/WOFF、PSD/ASEPRITE，以及配套 BIN/ATLAS/JSON。其他格式明确报错，不默默漏交。
- 每个资产使用独立的稳定目录。单文件版本更新保留同格式的既有目标路径，即使原始文件改名；文件扩展名变化会产生新增及待移除。多文件版本按文件名对应，不推测文件角色或自动重写 GLTF 等外部依赖路径，需一并准备配套文件。
- 本期交付文件，不自动创建引擎场景、重绑场景引用、运行编辑器或修改引擎导入设置。配置表的 JSON/Lua 可执行数据输出仍为后续能力；同步的数据配置文档是 Markdown 说明。

## 变更保护与恢复

工程内 `.gamecreator-sync/manifest.json` 记录项目身份、引擎、文件来源、采用版本及 SHA-256 校验值。工程一次归属一个 GameCreator 项目；另一个项目不能直接接管已有清单。若需迁移项目身份，应先保留工程与备份，再人工核对接管，本期没有自动接管功能。

只有清单中的文件可成为待移除项；手工文件不会被清理。关闭整类同步会保留该类已交付文件；在开启的范围内取消模块、归档素材、切换目录或排除占位素材，会将旧文件列为待移除。未确认的旧文件继续跟踪，不会自动删除。

预览保留内容快照，十分钟后失效。应用前再次核对工程身份、清单及所有预览文件，期间发生修改需重新预览。现存未受管文件始终视为冲突，即便其内容相同。选择保留冲突不会把手工版本登记成 GameCreator 版本，下次仍会提示。

每次覆盖或移除都会备份，与旧「数据配置输出（预留）」中的备份开关无关。备份位于 `.gamecreator-sync/history/<记录ID>/files/<序号>`，对应记录 `files` 数组中的同序号文件；`before-manifest.json` 保存此前的清单。最近 100 条记录可在界面查看，备份不自动清理。工程中的 `.gamecreator-sync/.gdignore` 防止 Godot 导入备份。

整批写入失败时尝试恢复原文件；外部新修改不会被恢复流程覆盖。异常退出留下日志时，可在同步记录点击「恢复中断的同步」。若原同步进程仍在运行会拒绝恢复。恢复时校验备份与文件；无法安全恢复会保留日志和备份并报出具体路径。历史备份也可用于人工恢复已成功同步前的文件，本期没有历史版本一键回退。

路径检查拒绝绝对目标、目录越界、隐藏/保留目录、链接和输出目录互相包含。单批最多 4000 个文件、256 MB；单素材沿用 100 MB 原文件限制。不会写入脚本、引擎场景或 `.godot` 缓存。

## 验证

- `npm run test:engine-sync`：真实磁盘交付、素材换版、重复扫描、按范围移除、手工冲突、过期快照、路径/链接保护、备份回滚、中断恢复、两个引擎、原素材接口与文档导出回归。
- `npm run build` 后运行 `node tests/desktop-engine-sync.cjs`：隔离工程中验证桌面 UI、实际素材字节、文档内容、冲突决定、显式移除、记录、偏好重启恢复及窄窗口布局。
- Playwright 可通过 `GAMECREATOR_PLAYWRIGHT_PATH` 指定。所有测试使用临时工程，不会向用户已连接的游戏工程写入演示文件。
