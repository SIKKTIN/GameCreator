# 数值分析

本地项目的“数值分析”用于从配置和故事状态建立数值模型、比较调整方案。分析使用明确输入与公式；图表反映模型假设，不表示已运行真实战斗或经营模拟。

## 开始使用

1. 打开“数值分析 → 新建分析”，填写名称、假设与可选的关联玩法。
2. 在“参数与公式”添加参数。参数可以是常量、配置表的一条记录字段，或已启用故事编排中的状态初始值。公式使用界面显示的英文参数标识。
3. 添加指标，例如 `ceil(hp / damage)`，填写单位和可选目标上下限。
4. 在“分析结果”查看图表、明细、输入来源和超出目标提示，点击记录或图表数据点查看计算依据。
5. 在“方案对比”添加试算方案，勾选要覆盖的参数。数值覆盖仅保存在分析存档，原配置继续在“数据配置”管理。具有有效上下限的参数支持滑块。
6. “保存为基准”保留当时的输入、来源、指标公式和结果，最多保留最近 10 份。当前输入或规则变化时标记基准需核对，不自动替换历史结果。记录 ID 与采样值相同的结果才会对齐比较；基准值为零时不显示变化百分比。

数值输入兼容原来的文本配置。接受有限十进制或科学计数法，空白、`待配置`、带单位的文本不会当作零。百分比类型接受 `25%` 或 `0.25`，内部统一为 `0.25`；常量与试算覆盖也填写比例。整数与上下限在计算时检查。

单位由参数和指标声明。绑定参数表的 `value` 字段时，如果该记录有 `unit`，会检查它与声明的单位一致。首版不自动进行跨单位换算或公式量纲推导；应先通过公式换算，例如毫秒除以 1000，再与秒制数值组合。

## 批量和曲线

选择批量来源表后，可以使用全表或指定记录，最多 100 条。参数的来源记录可选“当前批量记录 ID”，也可选某个字段作为另一张表的记录 ID，例如作物记录中的种子 ID 指向物品表购买价。来源 ID 重复、记录或字段删除会显示错误。

曲线选择一个参数、起点、终点和正步长，最多 101 个采样点。批量与曲线可以结合，一次最多 1000 组结果。未落在步长上的终点不额外采样。采样值优先于试算方案覆盖，方案覆盖优先于原始输入。来源仍须存在且为有效数字，试算覆盖不能隐藏坏引用。

公式支持 `+ - * / ^`、`> >= < <= == !=` 和括号。函数包括 `min/max/abs/floor/ceil/round/sqrt/pow/clamp/if`；`if(条件, 成立表达式, 否则表达式)`只计算选中的分支。公式可以引用其他指标，循环依赖、除零、非有限结果都会报错。不执行 JavaScript，不支持属性访问、脚本、循环或网络调用；单个公式上限 1000 字符、300 个词法单元、40 层嵌套。

`diceChance(技能, 难度, 骰子数, 面数, 极值规则)` 返回 0～1 概率。支持 1～10 颗、2～100 面独立均匀骰子，极值规则 1 表示全最小必败、全最大必成，0 表示关闭。使用骰点和分布计算精确模型概率，无随机抽样。

## 故事检定

在“添加分析示例”中可选择当前故事的一次检定创建方案。`storyChance()`实时引用它的数值比较/骰子模式、难度和条件修正；状态参数使用故事初始值，可在方案中覆盖。故事试玩与分析共用判定规则。该概率只指给定状态下的一次尝试，不包含剧情是否可达、重试次数或整条故事成功率。

## 五套示例与已有项目

新版原型模板包含 13 个分析方案：空洞骑士 2 个、星露谷 1 个、植物大战僵尸 3 个、极乐迪斯科 5 个、吸血鬼幸存者 2 个。全部使用本工具原型的设计数值。

已有项目不会随 Git 更新自动替换存档。直接使用“数值分析 → 添加分析示例 → 选择原型 → 添加所选示例”，即可新增方案并使用当前配置。表名、记录 ID 或字段已经自定义时，可以在新增方案中重新绑定。此操作保留原玩法、地图、故事、配置与已存在的分析方案。重复添加会创建独立方案。

模板可由 `node scripts/build-analysis-examples.mjs` 确定性重建，再执行 `node scripts/validate-prototype-examples.mjs`。生成器只更新版本管理的示例，不触碰运行目录中的项目存档。

## 存档与交付

存档键为 `gamecreator.workspace.v1:<项目ID>:numerical-analysis`，独立 schema 1。旧项目没有该存档时显示空目录，读取不写入。保存失败保留草稿并阻止项目切换、测试工作区切换和正式导出；可重试，或先下载 JSON 草稿再重新读取存档。过期写入与损坏存档不会覆盖已保存内容。

方案、试算和基准随项目文件夹迁移，旧文件夹缺少该模块时读为空。AI 文档包含参数绑定、指标公式、目标、计算假设、各方案结果和异常；单方案超过 100 行时使用 CSV 获取完整明细。CSV 包含输入、结果与异常，并对可能被电子表格解释为公式的文本做转义。

当前支持本地项目；团队共享留待接入服务端权限与版本控制。时间过程模拟、自动玩家策略、实际物理命中和完整战斗/经营仿真不在本版范围。
