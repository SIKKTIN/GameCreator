# 素材制作方案

在“素材资产 → 制作方案”中记录技术路线、制作工具、操作步骤和交付约定。

方案是自由编辑的 Markdown 文档，可从空白开始或使用可修改的制作方案模板。文档支持标题、列表、链接、代码块和正文图片；“阅读预览”查看排版结果，不执行正文代码或 HTML。

分类通过文档分类字段创建和调整，目录可按分类、标题或正文查找。每份文档可选关联多个素材需求和资产，点击关联可进入对应条目。被制作方案引用的素材不能直接删除，应先解除关联。删除方案只移除文档及其关联记录，不删除素材需求或资产。

例如《僵尸骨骼动画制作方案》可说明二维分件方式、骨骼动画工具、共用骨架、动作清单、导出格式与 Godot 接入方法。工具和技术选择都写在正文中，不要求额外填写审核状态或技术参数表。

正文图片通过“插入图片”导入到当前项目的受管素材目录，原始图片位置改变后仍可预览。文档及图片随自动保存、另存为和项目文件夹迁移保留。正文中的 `material-image:` 是受管图片引用，不应手动修改标识。

制作方案内容包含在素材资产的 AI 文档中。通过工程同步同步“素材资产”文档时，正文写入 `文档目录/modules/content/art.md`，使用的插图写入 `文档目录/media/`，Markdown 使用相对路径。插图属于文档附件，不依赖游戏素材的审核或采用状态；关闭素材资产文档同步时不会新增这些插图。旧项目没有制作方案字段时显示空列表，不影响原有素材记录。
