# 美术资产

美术资产模块把制作需求与交付素材分别管理，适用于占位素材验证到正式美术交付的过程。新建需求或资产只需名称，其他信息可以逐步补充，无需先绑定引擎目录。

## 美术需求

“美术需求”维护分类、说明、制作规格、验收标准、负责人、优先级、日期和进度。分类覆盖角色、场景、动画、特效、UI、图标及其他。

需求可以关联整份玩法、条件规则、状态、时间事件、空间对象及程序功能。关联按稳定 ID 保存；改名后显示最新名称，来源失效会提示并保留记录供修复。玩法设计与功能说明显示反向的美术需求入口。

一个需求可关联多项资产，例如角色需要待机动画、攻击动画和卡牌图标。同一项资产也可以被多个需求复用，资产不因被多次引用而复制。

## 交付版本与审核

“资产库”维护每项素材及其交付版本。导入新版本时可以多选文件，填写版本名称、备注并指定是否属于原型占位。文件和版本内容提交后保留为历史记录；替换素材应导入新版本。

每版单独记录待审核、需修改或已通过及审核反馈。占位版本可先采用；正式版本须审核通过才能采用。采用新版本不会删除旧版本，历史已通过版本可再次采用。

需求“已通过”要求至少关联一项资产，且所有关联资产都采用了非占位、已通过的版本。占位可用与正式交付完成分开显示。需要撤回正在采用的正式版本审核时，先调整关联需求的状态并取消采用，避免已通过需求静默失效。

已归档需求和资产只读，现有引用保留，恢复后可以继续编辑。首版不提供物理删除历史交付文件。文件复制成功后若取消版本提交，本地副本会保留为未关联文件；不会自动清理已有文件。

## 卡片删除

在需求目录、资产目录或分类首页搜索结果中，右键卡片选择“删除素材需求 / 删除素材资产”，确认后删除。键盘聚焦卡片后可用 Shift+F10 或菜单键打开菜单；Escape 关闭菜单或取消确认。右键操作始终针对该卡片，不会误删右侧正在编辑的其他条目。

删除需求会移除需求及其资产关联，保留所有关联资产。删除资产会移除卡片与交付版本记录，已导入的本地文件继续保留。分类映射和当前选中详情同步更新；归档条目也支持明确确认后删除。普通编辑仍不允许修改、删除已有版本内容。

资产被需求、原型元素、地图对象、任务、故事角色头像、故事文档或项目排期引用时，确认窗口列出引用位置并停止删除。需求被故事文档或项目排期引用时也需要先解除引用。检查包含已归档内容及已关闭模块，避免恢复后引用失效。

删除单独写入已提交的存档，成功后才更新界面；失败时卡片保留，可在窗口中重试。有未保存修改或关联存档不可读时暂不可删除，其他窗口已修改存档时要求重新打开项目。

## 文件与保存

元数据按项目存入 `gamecreator.workspace.v1:<项目标识>:art-assets`，schema 1。旧项目默认空目录，只查看不会写入空档案。项目之间以及正式/测试工作区之间独立保存。

桌面导入使用系统文件选择器，将文件复制到 `.gamecreator/art-files/` 下按项目隔离的目录中，不依赖导入来源继续存在。PNG、JPEG、WebP、GIF 可预览；其他格式保留交付文件，可在文件夹中定位。单文件最大 100 MiB，图片预览最大 12 MiB，且需满足有效图片结构、宽高各不超过 16384 和总像素不超过 4000 万。SVG/HTML 不作为内嵌页面执行。

备份时应复制整个 `.gamecreator/`，包括元数据、备份和文件目录。浏览器开发模式可以管理需求、版本元数据和关系；文件导入与本地预览需使用桌面软件。

保存失败保留当前草稿并提供重试；未保存时保护项目切换、测试工作区切换、退出登录、关闭窗口和 AI 导出。损坏存档停止写入，版本冲突不覆盖其他窗口数据。

AI 文档导出需求规格、来源、进度、关联资产、交付历史、审核反馈及当前采用版本。每份完整需求和资产只输出一次，玩法及功能章节使用引用。导出不打包图片或二进制交付文件。

## 验证

- 构建：`npm run build`
- 模型与文件存储：`node --test tests/art-assets.test.mjs tests/art-deletion.test.mjs tests/art-library.test.mjs tests/art-files.test.cjs`
- 桌面验收：`node tests/desktop-art-assets.cjs`，通过 `GAMECREATOR_PLAYWRIGHT_PATH` 指定 Playwright 模块路径。使用隔离存档，不覆盖真实项目。
- 卡片删除验收：`node tests/desktop-art-deletion.cjs`，覆盖右键与键盘、取消、引用保护、归档版本、本地文件保留、失败重试、跨窗口冲突、分类搜索结果及重启。
